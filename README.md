# Dylan Gaeta

Postdoctoral Research Associate, NOAA Global Monitoring Laboratory (CIRES/NOAA), Boulder, CO.

Research: atmospheric trace gas emissions, geostatistical inverse modeling, carbon cycle science, drought research.

## Projects

- **[Western US Snow Drought Dashboard](https://dylan-gaeta.github.io/snow-drought/)** ([repo](https://github.com/dylan-gaeta/snow-drought)) — interactive dashboard tracking snow drought and its carbon-cycle impacts across the Western US, built on a multi-product observational pipeline spanning snow, climate, drought, water, vegetation, carbon, and fire data.
